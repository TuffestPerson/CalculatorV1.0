# КАЛЬКУЛЯТОР
Перед началом работы с данным кодом прошу вас ввести в терминал данную команду:


## КАК ПОЛЬЗОВАТЬСЯ
1.Скачайте архив с файлом и разархивируйте его

2.Для его запуска по возможности скачайте любой интерпретатор питона(VScode,PYcham и Т.Д.) и сам python

3.В терминале(в PYcharm,VScode он встроен) введите команду
```
pip install -r requirements.txt
```

### Cсылки для скачивания:

[Python:](https://www.python.org/downloads/)

[VScode:](https://code.visualstudio.com/download)

[PYcharm:](https://www.jetbrains.com/ru-ru/pycharm/download/?section=linux)

4.После запуска кода в интерпретаторе вы увидите текстовое меню, предлагающее выбрать одну из доступных математических операций: сложение, вычитание, умножение, деление, возведение в степень или извлечение квадратного корня. Для выбора операции необходимо ввести соответствующую цифру (от 1 до 7) и нажать клавишу Enter.

В зависимости от выбранной операции, программа предложит ввести одно или два числовых значения. Важно помнить, что для корректной работы необходимо вводить именно числа. Если ввод будет некорректным, программа выдаст сообщение об ошибке и предложит повторить ввод.V

Результат выполненной операции будет отображен на экране в удобном формате. Например, при сложении вы увидите выражение, показывающее слагаемые и их сумму. Для извлечения квадратного корня будет показано исходное число и результат вычисления.


Для завершения работы с калькулятором необходимо выбрать пункт  "7. Выход".
